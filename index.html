Features

Everything you need to understand your day

From passive tracking to AI-generated insights, DayRecall gives you full visibility into how you spend your time.

🪟

Active Window Tracking

Logs the foreground application and window title every 2 seconds with smart idle detection so you only get real work time.

🧠

AI Daily Digest

Summarizes your day into top apps, domains visited, and article takeaways — powered by local LLMs (Ollama) or OpenAI.

🧩

Chrome Extension

Monitors browser activity, active URLs, tab titles, and time spent per page — including SPA navigation. Required for enhanced analytics and the full tracking experience.

🌐
📄

Article Summarization

Automatically fetches and summarizes long-form articles via SmartReader every 15 minutes so you can revisit key ideas.

💬

AI Chat

Ask natural-language questions about your day — "What was I working on at 10:42?" — and get instant answers.

🔍

Global Search

Full-text and semantic search across activity, browser history, articles, bookmarks, and more.

📊

Dashboard & Analytics

Visual breakdown of time spent across apps and domains with live-updating charts and per-project aggregates.

⏱️

Timeline Playback

Replay any day as contiguous frames and see exactly what you were doing at any given minute.

📦

Backup & Export

Timestamped SQLite snapshots with pruning, plus export to CSV, JSON, Markdown, or PDF.

How it works

Three steps to total time awareness

Get started in minutes. No account, no cloud sync, no configuration required.

1. Install & launch

Download the standalone Windows executable and double-click to run. No .NET runtime or SDK needed.

  • Self-contained single-file EXE
  • Works on Windows 10 and 11
  • Runs minimized to system tray
  • Optional auto-start with Windows
💻
Windows desktop app

2. Track passively

DayRecall silently records your active window and browser activity in the background. Install the Chrome extension for deeper web tracking and better analytics.

  • Active window + title logging
  • Browser URL and tab tracking
  • Idle detection built-in
  • Local SQLite database storage
📡
Passive background tracking

3. Review & ask AI

Open the dashboard to see charts, timelines, and daily digests. Chat with your data to uncover productivity patterns.

  • AI daily summaries
  • Natural-language Q&A about your day
  • Exportable reports (PDF, CSV, JSON)
  • Backup & restore snapshots
🧩
Blazor dashboard + AI chat
Privacy

Your data never leaves your machine

DayRecall is built on the principle that productivity tools should not require sacrificing your privacy.

🏠 100% Local

All data is stored in a local SQLite database. No cloud sync, no telemetry, no external servers.

🔒 Offline AI

Use Ollama to run LLMs locally for digests and chat. No API keys or cloud AI required.

🛡️ Secure API

Loopback-only REST API with optional CSRF token protection. Your data stays between your apps.

🔐 Open Source

Fully transparent codebase on GitHub. Audit, modify, and contribute freely under MIT license.
